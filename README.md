# About PVEstrap
### 'PVE'/PVEstrap is a whole suite of specialized suite of tools and designed built for your Windows Machine to simplify and optimize AFK-ing inside Roblox experiences. Bootstrapper, input management, Discord automation and more keeping everything as beginner/user-friendly as possible. Built by one person, with the care and love of a full team.
